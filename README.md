# 🌤️ Weather Buddy

Weather Buddy is a beginner-friendly web application that shows current weather details
and provides friendly suggestions based on temperature.

## Features
- Search weather by city
- Shows temperature, condition, humidity, wind speed
- Friendly weather messages
- Simple and clean UI

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How to Run
1. Download or clone the project
2. Open index.html in a browser
3. Enter a city name and search
